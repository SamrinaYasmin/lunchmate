# Lunchmate

Lunchmate helps families answer “what’s for lunch?” with meal ideas based on children’s favorites, available ingredients, and time.

## What it can do

- Save each child’s favorite foods in this browser and rank matching lunch ideas higher.
- Add ingredients or tap a vegetable shortcut to find meals that use what is on hand.
- Open a recipe with ingredients and simple cooking steps.
- View a seven-day lunch menu and choose a different dish for any day.
- See a simple meal-balance guide for each dish.

This first version is a static website. Preferences and menu changes stay in the current browser; there is no account or shared database yet. Meal-balance scores are planning hints, not medical nutrition advice.

## Run locally

Open `index.html` in a browser, or run a local static web server from this folder.

## GitHub Pages

The workflow in `.github/workflows/deploy-pages.yml` publishes the static site from the `main` branch. In the repository settings, choose **Settings → Pages → Build and deployment → GitHub Actions** if Pages has not been enabled for the repository yet.
